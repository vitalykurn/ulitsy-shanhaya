# Hermes: как добавить пост в сообщество ВК

Сообщество: `https://vk.ru/ulitsy_shanhaya` (тот же адрес открывается как `https://vk.com/ulitsy_shanhaya`).  
Стена владельца: `-242730578`.  
Тексты: [posts.txt](posts.txt). Правила фактов и голоса: [sistema-publikatsii.md](../prompts/sistema-publikatsii.md).

Публиковать только после явной просьбы человека. Сам по расписанию на стену ничего не класть.

---

## 1. Что можно публиковать

Один пост = одно сообщение. Внутри: русский абзац, пустая строка, китайский. Языки не делить на два поста.

Брать текст целиком из блока `posts.txt`:

| Блок | Куда |
| --- | --- |
| ПОСТ 1 … ПОСТ 4 | обычные посты, если такого начала на стене ещё нет |
| ЗАКРЕП | отдельный пост, затем Pin. Ссылка на `https://ulitsy-shanhaya.ru/` уже в тексте |
| ПОСТ 5 | флотилия Старка, без фото. Публиковать, если первой русской фразы на стене ещё нет |
| ПОСТ 6 | черновик про Иоанна. Не публиковать, пока человек не назвал этот пост |
| ПОСТ 7 | школа «Реми», без фото. Публиковать после ПОСТ 5, не раньше чем через час |

Перед отправкой открыть стену и сравнить первую русскую фразу. Если она уже есть, пост не дублировать.

Не публиковать:

- длинные тексты из Telegram за 1–3 ноября 2026 (школа «Реми», второй текст про собор, «как лётчики спасли Шанхай»);
- адрес, которого нет на сайте. У 1950 года дома нет, булавка на Вайтань или в случайное здание запрещена;
- новый текст, которого нет в `posts.txt` и на сверенной странице сайта.

## 2. Картинка к посту

Файл класть в тот же пост, не отдельным сообщением. Чужое фото не называть своим: в текст подпись «это моё фото» не добавлять.

| Пост | Файл |
| --- | --- |
| ЗАКРЕП | `site/img/vera.jpg` |
| ПОСТ 1 Пушкин | `site/img/pushkin.jpg` |
| ПОСТ 2 храмы и Хуайхай | `site/img/sobor.jpg`, `site/img/nikolsky.jpg`, `site/img/huaihai.jpg` |
| ПОСТ 3, 1950 | без фото |
| ПОСТ 4, 1955 | `site/img/vystavka.jpg` |
| ПОСТ 5, флотилия Старка | без фото |
| ПОСТ 7, школа «Реми» | без фото |

Если у поста фото уже стоит, второе такое же не прикреплять.

## 3. Вход

Работать в обычном Chrome, где человек уже вошёл в сообщество. Headless не использовать.

Пароль не угадывать. Если сессии нет, читать его только из локального `vk.env` (первая строка — пароль, вторая — телефон `+86`). В ответ и в логи пароль не писать.

Остановиться и звать человека, если на экране:

- `challenge.html` или «I'm not a robot»;
- код из SMS или MAX;
- «too many attempts» / «подождите N секунд».

После капчи не повторять вход пачкой. Одна попытка, затем пауза.

## 4. Новый пост

1. Открыть `https://vk.ru/ulitsy_shanhaya`.
2. Нажать широкую кнопку **Create** над вкладками Posts / Clips / Videos. Кнопку **Create** в баннере «Set up your community» не нажимать.
3. В меню выбрать **Post**. Если открылся New clip, Video или Article — закрыть и начать снова.
4. В поле `contenteditable` вставить весь блок: русский, пустая строка, китайский. Текст не переписывать.
5. Если для этого поста есть файл из таблицы выше — **Upload from device** / поле `input[data-testid="posting_base_screen_download_from_device"]`. Дождаться в редакторе надписи **Photo/Video**. Пока её нет, **Next** не нажимать: иначе сохранится текст без картинки.
6. **Next**.
7. **Publish**. Не **Schedule**. Не ставить галочку «Publish as post» на чужом шаге (аватар, обложка).
8. Дождаться, пока окно закроется. На стене должна быть первая русская фраза и, если файл был, ссылка `/photo-242730578_…`.

Между двумя публикациями пауза 60–90 секунд. Следующий пост не раньше чем через час. Лучше один пост в сутки.

## 5. Картинка к уже стоящему посту

Текст не менять.

1. Открыть пост: `https://vk.ru/wall-242730578_<id>` или найти его на стене по первой фразе.
2. **Actions** (⋯) этого поста → **Edit**. Не **Delete**, не **Pin**, если закреп не просили.
3. Прикрепить файл тем же полем, что в §4. Дождаться **Photo/Video**.
4. **Next**, затем **Save**. Кнопка может коротко показать «Загрузка…» — не нажимать её второй раз.
5. Обновить страницу. Фото видно у своего текста, первая фраза та же.

Сейчас на стене уже есть:

| id | Текст | Фото |
| --- | --- | --- |
| 6 | закреп «Здравствуйте. Меня зовут Вера…» | есть |
| 5 | выставочный центр, 1955 | есть |
| 4 | «Я сначала смешала Шанхай и Корею…» | нет, так и оставить |
| 3 | «Синьлэ, 55…» | три кадра |
| 2 | «Памятник Пушкину стоит…» | есть |

## 6. Если ВК режет

Стоп на 2–5 минут. Не слать `wall.post` параллельно и не обновлять стену каждые 15 секунд. Капчу кликает человек. После этого один медленный пост через окно, не через пачку запросов.

Готово, когда пост виден на `https://vk.ru/ulitsy_shanhaya` без ошибки и без второго такого же текста.
