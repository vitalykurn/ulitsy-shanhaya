# ВКонтакте: аккаунт и сообщество для заявки

Первое поле «Аккаунт проекта в социальной сети» — **сообщество ВК**, не личная страница ребёнка.  
Готовая ссылка: `https://vk.com/ulitsy_shanhaya`  
Тексты: [posts.txt](posts.txt). Родительский чеклист: [kak-zavesti.md](kak-zavesti.md).

Ниже — как это делается по шагам: вход во ВК ID, создание сообщества, описание, посты, закреп, запись ссылки в заявку.

---

## 0. Что считаем «аккаунтом проекта»

| Нужно | Не нужно |
| --- | --- |
| Сообщество (группа / публичная страница) | Личный профиль на имя Веры |
| Владелец — взрослый (родитель) | Отдельный «детский» VK ID без SMS |
| Адрес вида `vk.com/ulitsy_shanhaya` | Мёртвая ссылка на сайт, пока домен не открывается |

Личный VK ID нужен только как **владелец** сообщества: без него создать сообщество нельзя. Имя профиля владельца держать нейтральным (не полное ФИО ребёнка как «личная страница-персона»).

Секреты (пароль, телефон) — в корневом файле `vk.end` (в git не попадает; в `.gitignore` уже есть `vk.end`).

## 1. Вход / регистрация VK ID

### 1.1. Открыть форму

1. Браузер → `https://vk.com/join` или главная `https://vk.com` → **Sign in** / **Other sign-in options**.
2. Рабочий поток идёт через **VK ID**: `https://id.vk.ru/...` (редирект с `vk.com` / `vk.ru` нормален).
3. Прямой URL `https://id.vk.ru/auth?action=register` без `app_id` из основного сайта часто показывает ошибку загрузки (`Access denied: token required`). Надёжнее заходить со страницы `vk.com`.

### 1.2. Телефон

1. Режим **Phone**.
2. Код страны: флаг у поля → поиск страны → **China +86** (или другой код по факту номера).
3. Ввести национальный номер без `+86` (пример: `15601694273`).
4. **Continue** / **Sign in**.

### 1.3. Если номер уже занят

ВК пишет, что номер привязан к существующему VK ID (в нашей сессии: аккаунт вида «Test B.»).

Тогда **новый** аккаунт на этот номер не создаётся. Варианты:

1. **Войти в старый** (пароль или SMS / MAX).
2. Если пароль забыт: `https://vk.com/restore` → **Phone** → код на SMS/MAX → смена пароля → **Sign in to account**.
3. Если вход по паролю заблокирован («too many attempts») — подождать несколько часов или выбрать **Confirm using other method** → **Phone number** / SMS.
4. Кнопка «This isn't my account» **не** открывает вторую регистрацию на тот же номер: номер занят, дальше поддержка или другой телефон.

Пароль после смены сохранить в `vk.end` (первая строка — пароль, вторая — телефон).

### 1.4. Проверки робота и SMS

На пути встречаются:

- капча **I'm not a robot** (iframe `not_robot_captcha`);
- страница `challenge.html` («Проверяем, что вы не робот») → **Продолжить**;
- код в 6 клеток (`otp-cell`) из SMS или MAX.

Код вводится сразу; после верного кода ВК либо пускает в ленту, либо (для «пустого»/нового профиля) показывает анкету имени.

### 1.5. Анкета нового профиля (если появилась)

Если после кода идёт «You're creating a VK account» / «Information about you»:

1. First / Last name — нейтральные (например «Улицы» / «Шанхая»), **не** полное ФИО ребёнка.
2. Gender / Birthday — заполнить минимально, если без этого кнопка неактивна.
3. **Continue**.

После входа должна открыться лента / `vk.com` с боковым меню (Profile, Communities, …).

## 2. Создать сообщество

### 2.1. Открыть создание

1. Меню → **Communities** / **Сообщества**.
2. Кнопка **Create community** / **Создать сообщество**.
3. URL часто становится `https://vk.com/groups?w=groups_create_new`.
4. Форма может грузиться во **iframe** `static.vk.ru/community_create/` — подождать, пока исчезнет спиннер.

### 2.2. Поля формы

| Поле | Значение |
| --- | --- |
| **Name** | `История России на улицах Шанхая` (из `posts.txt`, «НАЗВАНИЕ СООБЩЕСТВА») |
| **Category** | **Education** (или «История» / «Образование» в русской локали) |
| **Business tools** | не включать (галочку не ставить) |

### 2.3. Создать

1. **Create community**.
2. После успеха — страница клуба вида `https://vk.com/clubXXXXXXXX` и баннер «Сообщество создано».
3. Дальше назначить короткий адрес (см. §3).

Если снова вылезла проверка «не робот» — **Продолжить**, страница настроек должна догрузиться.

### 3.1. Основное

| Поле | Значение |
| --- | --- |
| **Name** | `История России на улицах Шанхая` |

Короткое описание в боковой карточке берётся из Description; отдельное «короткое» поле в новой форме может отсутствовать — достаточно полного текста из `posts.txt`.

## 4. Как добавлять посты

Источник текстов: [posts.txt](posts.txt).  
Правило файла: **один пост = одно сообщение**; внутри русский, пустая строка, китайский (языки не делить на два поста).

### 4.1. Порядок публикации

1. Сначала четыре истории: **ПОСТ 1 … ПОСТ 4** (Пушкин → храмы/Хуайхай → 1950 → 1955).
2. Затем вводный текст **«ЗАКРЕП»** (или **ПОСТ 0**, если нужен приветственный вариант без ссылки — для ВК с открытым сайтом использовать **ЗАКРЕП** со ссылкой на `https://ulitsy-shanhaya.ru/`).
3. Закрепить вводный пост (звезда / **Pin post**).

Ссылку на сайт в текст ставить **только** когда домен открывается (сейчас — да).

### 4.2. UI публикации (текущий ВК)

1. Страница сообщества `https://vk.com/ulitsy_shanhaya`.
2. Кнопка **+ Create** / **Create** над лентой (**не** путать с «Create» в баннере «Set up your community» — это другой сценарий).
3. В меню выбрать **Post** (не **Clip**, не **Video**, не **Article** — иначе откроется загрузка файла/клипа).
4. В модалке **New post**:
   - поле текста (`contenteditable`);
   - вставить **весь** блок поста (RU + пустая строка + ZH);
   - фото не обязательны;
   - **Next**;
   - **Publish** (не Schedule, если пост нужен сразу).
5. Дождаться исчезновения модалки и появления текста на стене.

### 4.3. Закреп

1. На опубликованном вводном посте → **Actions** (⋯).
2. **Pin post** / **Закрепить**.
3. У поста должна появиться пометка Pin / звезда; пост уходит вверх стены.

### 4.4. Типичные сбои при публикации

| Симптом | Что делать |
| --- | --- |
| Открылось **New clip** | Закрыть (X / Escape), снова Create → именно **Post** |
| После Create меню не видно | Прокрутить ленту, кликнуть широкую кнопку Create над вкладками Posts/Clips/Videos |
| Текст вставлен, но Publish крутится | Подождать 3–5 с; обновить страницу и проверить стену |
| challenge / «не робот» | Продолжить, затем повторить действие |
| Капча / rate-limit / «подождите N секунд» | См. §4.5 |

### 4.5. Капча и rate-limit (для автоматизации / Hermes)

ВК часто режет частые API-запросы и скрипты. Telegram при этом может работать нормально — это ожидаемо.

**Сразу после блокировки «15 секунд» / flood:**

1. **Стоп.** Не слать новые запросы 2–5 минут (не «через минуту снова 20 попыток»).
2. Один раз открыть в обычном браузере (не headless): `https://vk.com/ulitsy_shanhaya`.
3. Если есть капча / «I'm not a robot» / `challenge.html` — кликнуть **человеком**, не скриптом.
4. Если просят SMS / код в MAX — один код, один ввод. Не перезапрашивать код подряд.
5. **Один** пост вручную или одним медленным проходом UI (§4.2). Между постами пауза **≥ 60–90 с**.
6. Cron/API на ВК пока **не** крутить. Cron Telegram оставить.

**Не делать:**

- цикл «попробовать ещё раз» каждые 15 с;
- параллельные `wall.post` / много вкладок с публикацией;
- обход капчи через сторонние сервисы;
- SMS-подтверждение «наугад» без окна, где ВК реально просит код.

**Если нужен тестовый пост «Пушкин»** — копировать целиком блок **ПОСТ 1** из `posts.txt` (RU + пустая строка + ZH), один раз Publish.

**Критерий успеха:** пост виден на `https://vk.com/ulitsy_shanhaya` без ошибки. После этого можно планировать следующий пост не чаще 1 раза в час (лучше по cron раз в сутки, как в Telegram).

## 7. Автоматизация (как это делал агент в сессии)

Краткая схема, если повторять через браузер с remote debugging:

1. Chrome с `--remote-debugging-port=9222` и отдельным user-data-dir.
2. CDP / WebSocket к вкладке: навигация, `Runtime.evaluate`, клики через `Input.dispatchMouseEvent`, ввод через `Input.insertText`.
3. Форма создания сообщества часто в **iframe** `community_create` — клики считаются относительно iframe + сдвиг родителя.
4. Коды SMS и пароль агент **не** угадывает: их даёт человек; пароль читается только из локального `vk.end`.
5. Капчи «I'm not a robot» / challenge иногда требуют ручного клика человека.

Ручной проход по §1–6 достаточен без автоматизации.
