# Telegram-канал для заявки

Второе поле «Аккаунт проекта в социальной сети» — публичный канал. Первое поле — ВКонтакте.

Канал заводит **@vitaly_kur** (как в [kak-zavesti.md](kak-zavesti.md)). Личный аккаунт Веры не нужен.

## 1. Создать канал (5–10 минут)

1. Telegram → **Новый канал** (или «Create Channel»).
2. **Название:** `История России на улицах Шанхая` (как в `posts.txt`, блок «НАЗВАНИЕ СООБЩЕСТВА»).
3. **Описание** — из `posts.txt`, блок **«TELEGRAM, ОПИСАНИЕ КАНАЛА»**: русский, пустая строка, китайский.
4. Тип: **публичный канал**.
5. **Ссылка (username), по порядку попробовать:**
   - `ulitsy_shanhaya`
   - `karta_shanhaya_ru`
   - `istoriya_ru_shanghai`
   - `vera_shanghai_map`  
   Если Telegram пишет, что имя занято — следующий из списка.
6. **Фото канала:** файл `social/avatar.png` (знак маршрута, не портрет).

## 2. Посты

Сначала **ПОСТ 0** (приветствие). Затем **четыре поста** («ПОСТ 1» … «ПОСТ 4»). В каждом сообщении: русский текст, пустая строка, китайский (как в `posts.txt` или `telegram_soobsheniya.txt`).

Затем отдельным сообщением — текст **«ЗАКРЕП»** из `posts.txt` и **закрепить** его (как закреплённый пост в ВК).

Ссылку на сайт `ulitsy-shanhaya.ru` в посты **не** вставлять, пока домен не открывается у вас и в России (см. [kak-zavesti.md](kak-zavesti.md)).

## 3. Записать ссылку в проект

Готовую ссылку вида `https://t.me/имя_канала` сохранить в файл **`telegram.end`** в корне проекта (одна строка, только URL). Файл в git не попадает.

Обновить черновик заявки в `texts/zayavka.txt`:

- **Соцсети, строка 2:** ссылка на Telegram;
- **Соцсети, строка 1:** ссылка на ВК, когда сообщество готово.

Кнопку **«Отправить»** на форме премии не нажимать из этой работы.

## 4. Зачем два канала (ВК + Telegram)

- **ВК** — основная ссылка для жюри в России.
- **Telegram** — вторая соцсеть в форме; у одноклассников в материковом Китае Telegram часто не открывается, для экспертного совета в РФ — открывается.

WeChat, Xiaohongshu и Douyin для этой заявки не используем.
